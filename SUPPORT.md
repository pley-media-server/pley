# Getting help

- **Questions**: check the [docs](README.md#docs), then ask in
  [Discussions → Q&A](https://github.com/pley-media-server/pley/discussions/categories/q-a).
- **Bugs**: [report one](https://github.com/pley-media-server/pley/issues/new?template=bug_report.yml)
  with the server's version and, for an app, the app's version and device.
- **Feature requests**: start them in
  [Discussions → Ideas](https://github.com/pley-media-server/pley/discussions/categories/ideas),
  where others can vote. A small, clear one can be
  [an issue](https://github.com/pley-media-server/pley/issues/new?template=feature_request.yml).
- **Vulnerabilities**: report them privately ([SECURITY.md](SECURITY.md)).
- **Chat**: [Discord](https://discord.gg/wSsVdRRnT3).
