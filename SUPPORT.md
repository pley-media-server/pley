# Getting help

- **Setting Pley up or using it**: the [docs](README.md#docs) first, then
  ask in [Discussions → Q&A](https://github.com/pley-media-server/pley/discussions/categories/q-a).
  When an answer solves it, mark it as the answer.
- **Something that's broken**: [report a bug](https://github.com/pley-media-server/pley/issues/new?template=bug_report.yml),
  with the server's version and, for an app, the app's version and the
  device.
- **A feature you'd like**: suggest it, or vote for it, in
  [Discussions → Ideas](https://github.com/pley-media-server/pley/discussions/categories/ideas).
  Issues are for bugs.
- **A vulnerability**: report it privately, as [SECURITY.md](SECURITY.md)
  says.
- **A chat**: [Discord](https://discord.gg/wSsVdRRnT3).
